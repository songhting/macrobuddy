# 营养模型参考 · nutrition-model.md

本文说明 MacroBuddy 如何把用户档案换算成可执行的单餐营养目标，以及每一步的依据。
所有计算由 `scripts/nutrition_target.py` 实现，可逐行核对。

---

## 1. 基础代谢率（BMR）

采用 **Mifflin-St Jeor (1990)** 公式：

```
男性：  BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄 + 5
女性：  BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄 − 161
未指定性别：取两式常数中点，即 −78
```

选择该式的原因：在非肥胖与超重人群中对静息代谢率的预测误差普遍小于
Harris-Benedict 修正式，且只需要四个易得参数。

校验示例（175 cm / 72 kg / 30 岁男性）：
`10×72 + 6.25×175 − 5×30 + 5 = 1668.75 kcal`

未指定性别时不做性别推断，直接取中点并提示用户"这会降低目标精度"，
避免把结果强行归入某一性别。

---

## 2. 每日总消耗（TDEE）

```
TDEE = BMR × 活动系数
```

| 活动量 | 系数 | 描述 |
|---|---|---|
| `sedentary` | 1.200 | 久坐，几乎无运动 |
| `light` | 1.375 | 每周 1-3 次轻度运动 |
| `moderate` | 1.550 | 每周 3-5 次中等强度运动 |
| `active` | 1.725 | 每周 6-7 次高强度运动 |
| `athlete` | 1.900 | 体力劳动或一日两练 |

---

## 3. 目标热量调整

| 目标 | 热量系数 | 蛋白质 (g/kg) | 脂肪供能比 |
|---|---|---|---|
| `cut` 减脂 | ×0.80 | 1.8 | 25% |
| `maintain` 维持 | ×1.00 | 1.4 | 28% |
| `bulk` 增肌 | ×1.10 | 1.8 | 25% |
| `glucose_control` 控糖 | ×0.95 | 1.6 | 32% |

减脂采用 -20% 而非更激进的缺口：过大的缺口在快餐场景下无法组合出可行方案，
且会牺牲蛋白质达标率，与本 Skill"给出可执行方案"的定位冲突。

蛋白质取值参考 ACSM / AND 关于运动人群 1.4-2.0 g/kg 体重的共识区间，
减脂期取偏上限以在热量缺口下保住瘦体重。

---

## 4. 三大营养素分配顺序

分配顺序为：**蛋白质与脂肪先定，碳水填余量**。

```
蛋白质量 = 目标系数 × 体重
脂肪量   = max(目标热量 × 脂肪供能比 ÷ 9, 0.6 g/kg × 体重)
碳水量   = (目标热量 − 蛋白质×4 − 脂肪×9) ÷ 4
```

脂肪下限 0.6 g/kg 用于保障必需脂肪酸摄入与内分泌功能。

**碳水回撤机制**：当计算出的碳水低于总热量的 15% 时（通常是高蛋白+高脂肪目标导致的），
把脂肪回撤至下限，将腾出的热量还给碳水：

```python
if carb_kcal < 0.15 * kcal:
    carb_kcal = 0.15 * kcal
    fat_kcal  = max(FAT_FLOOR, kcal - protein_kcal - carb_kcal)
```

这样做是为了保证方案在**真实菜单上组合得出来**——麦当劳的餐品普遍高脂低碳，
若允许碳水被压到接近零，算法会给出理论上正确但实际无解的目标。

---

## 5. 单餐摊分

每日目标按餐次均分（可传入自定义占比，如 `[0.25, 0.35, 0.40]`），
再扣除当日已摄入部分：

```
本餐目标 = 每日目标 ÷ 餐次 − 已摄入
```

**可接受区间**（用于判定方案是否"达标"）：

```
热量下限 = 本餐目标 × 0.90
热量上限 = 本餐目标 × 1.06
```

上限略窄于下限：热量超标比不足更难通过后续餐次弥补。

**溢出保护**：若已摄入量已超过当日目标，则把本餐热量下限固定在均分值的 35%，
其余营养素不为负，避免出现"目标为负、无单可点"的无效输出。

---

## 6. 钠

每日上限取 WHO 成人建议的 2000 mg，按餐次摊分。评分中超过单餐参考值即扣分，
超过 1.5 倍时该组合直接退出候选池（见 `scoring.md`）。

麦当劳餐品普遍含钠较高，这是本模型中最容易触发扣分的维度。
在推荐理由中会显式列出超标数值，便于用户自行取舍。

---

## 7. 已知局限

| 局限 | 影响 | 缓解方式 |
|---|---|---|
| 未纳入饱和脂肪、添加糖 | 控糖目标下精度不足 | 控糖预设已提高脂肪供能比；后续可接入营养明细字段 |
| 活动系数为粗粒度分级 | TDEE 存在 ±10% 误差 | 允许用户直接覆盖热量目标 |
| 未考虑个体代谢差异 | 个体偏差可达 ±15% | 输出定位为"参考区间"而非处方 |
| 未处理食物过敏原 | 安全相关 | 需用户自行确认餐品成分，Skill 不做过敏判断 |

本模型为通用区间估算，**不构成医疗或营养建议**。
涉及慢性病、孕期哺乳、进食障碍、未成年人等情况，应咨询医生或注册营养师。
